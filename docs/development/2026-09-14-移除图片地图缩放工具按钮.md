# 移除图片地图缩放工具按钮

## 任务目标

用户明确不需要放大、缩小和重置按钮；图片与地图统一通过手势操作。

## 实施计划

删除 HTML 图集和原图弹窗的缩放工具条与比例显示，同步 UI 规范、AGENTS 和 README。保留手势、键盘与前后翻页，验证后提交推送。

## 完成结果

已移除图集和原图弹窗中的放大、缩小、适配按钮、比例显示和工具条。规范升级 v0.9，AGENTS 与 README 明确后续不再提供这些控件。

## 验证情况

两份规范一致，HTML 仅字体路径不同；可执行脚本语法检查通过。浏览器确认图集及原图内没有缩放按钮，滚轮缩放、前后翻页和弹窗仍正常；手机宽度无横向溢出。
