# 首页与社团紧凑版式

## 任务目标

同步用户已确认的首页与社团列表紧凑设计，保持规范、HTML 与应用实际实现一致。

## 实施计划

1. 更新手机常用入口的名称、图标尺寸与间距说明，补充分隔列表及轻量分类导航规则。
2. 更新内容优先样例，并增加可操作的社团组织列表样例；复用现有浮层筛选与整行入口交互。
3. 同步应用规范与 HTML，更新 README，检查差异与资源后提交推送 main。

## 完成结果

规范与展示已更新到 v0.13。首页样例使用短入口和紧凑间距；新增文字下划线栏目、整行分隔目录和单行简介样例，点击组织可查看完整介绍。README 和版本记录已同步，字体变量及原有浮层筛选保持。

## 验证情况

- 两份规范完全一致；两份 HTML 除字体路径外一致。
- 2 段可执行脚本、1 段 JSON 解析通过；150 个 HTML ID 无重复；新增详情弹层引用与字体资源存在。
- 应用类型、定向 Oxlint 与生产构建通过。
- 浏览器安全策略拒绝打开本地 HTML，未进行浏览器布局与交互验收，没有绕过该限制。
- 最终差异仅包含本任务样例、规范、版本记录和开发日志；按 main 提交推送，由既有 GitHub Pages 配置发布。
