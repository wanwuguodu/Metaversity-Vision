# 统一应用字体规范

## 任务目标

与 Metaversity 应用统一阿里巴巴普惠体、字号、字重、行高和表单必填标识，让规范与交互展示提供一致的开发依据。

## 实施计划

1. 核对应用现状与现有 v0.2 规范。
2. 使用官方字体资源和完整授权，同步规范、README、展示页和后续维护规则。
3. 验证静态资源、展示页排版及与应用规范的一致性，检查差异并提交、推送。

## 完成结果

- 规范升级至 v0.3，与应用同名规范保持完全一致；继续使用原校园蓝视觉和既有交互示例。
- 接入普惠体 3.0 原版 Regular、Medium Web 字体、完整中英文授权及来源记录；与应用共用相同的字体、字号、字重和行高变量。
- 展示页同步标题 24/32、分区 18/26、正文与表单 16/24、辅助 14/22；必填使用红星。README 和 AGENTS.md 记录后续同步规则。

## 验证情况

- 开始时 main 分支工作区干净。
- 浏览器确认两个字重实际 loaded，五个文字档位及表单输入、标签、按钮的计算样式符合规范。
- 375、768、1440px 同源 iframe 视口及 100%/125% 文字尺寸下，无页面横向溢出和控件文字横向裁切。属于浏览器布局检查，未声明真机或截图审美验收。
- 与应用规范、5 个字体文件逐字节一致；与应用本地 HTML 除字体路径外一致。展示脚本语法、必填红星和 `git diff --check` 通过。
- 展示、文档、规则：changed-and-verified。发布沿用 main 分支的 GitHub Pages；推送后核对远端与在线资源，发布结果在本次交付中报告。
