# 手机字号与内容密度适配

## 任务目标

同步用户确认的手机字号与容器密度调整，电脑端保留当前比例。

## 实施计划

1. 共用字体增加手机语义档位；更新规范、维护规则和 README。
2. HTML 手机组件展示使用手机文字与容器比例，明确手机与电脑档位；与应用展示页保持一致。
3. 检查窄屏、文字放大与搜索/筛选交互；验证后提交推送。

## 完成结果

- 规范、README 与维护规则升级 v0.6；字体 CSS 增加手机档位和输入文字角色。
- HTML 字号示例随视口切换标注，手机组合始终显示手机档位，卡片及控件留白同步收紧。
- 字体 CSS 使用版本参数更新缓存，实际字库及授权保持原版。

## 验证情况

- 390px：标题 20px、分区 16px、正文 14px、辅助 13px，输入 16px。
- 320px 和 125% 文字放大无横向溢出；全局分类搜索正常，输入高度可增长。
- 1280px 展示正文仍为 16px，内嵌手机正文为 14px；两端文字档位各自生效。
- 两仓字体 CSS、规范与 HTML 同步检查通过，HTML 内脚本语法有效。
