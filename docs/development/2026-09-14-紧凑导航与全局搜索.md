# 紧凑导航与全局搜索

## 任务目标

同步用户确认的紧凑上下导航：首页顶部改为全局搜索，学校切换归个人页，业务页面不展示重复的演示环境横幅。

## 实施计划

1. 更新共用导航规范及版本说明。
2. 更新 HTML 导航示例，保持应用仓库展示页与本仓 HTML 一致（字体路径除外）。
3. 验证手机、桌面和文字放大布局及搜索/导航示例；核对差异后提交并推送。

## 完成结果

- 规范、README、维护规则和 HTML 同步为 v0.5。
- 手机示例顶部只显示功能与分类搜索；底部导航压缩为默认 53px；学校切换放在个人页。
- 搜索示例支持关键词、空结果、进入分类、返回和切换学校，不检索具体业务内容。

## 验证情况

- 390、1280px 的手机示例上下栏均为 53px；320px 和 125% 文字放大无横向溢出。
- 搜索图书馆、无匹配、分类返回、学校切换及原课程详情返回均通过浏览器验证，控制台无错误。
- HTML 内脚本语法检查通过；与应用 `docs/ui-design-preview.html` 除字体路径外一致；两仓 UI 规范内容一致。
- 最终差异检查通过，变更限定在导航、搜索及对应文档。
