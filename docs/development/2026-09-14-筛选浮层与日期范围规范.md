# 筛选浮层与日期范围规范

## 任务目标

同步 Metaversity 已确认并实现的列表筛选设计，将默认收起的筛选浮层、紧凑布局和起止日期范围用于后续所有相关页面，并在设计站 HTML 中提供可操作示例。

## 实施计划

1. 更新统一 UI 规范至 v0.4，同步 README 与 AGENTS.md 的后续开发约束。
2. 更新 index.html 的筛选示例和版本说明，支持桌面浮层、手机底部面板、44px 控件和范围两步选择；原字体、填写表单及其他示例保持。
3. 与应用仓库同步同名规范及 HTML，核对路径差异、脚本、响应式布局、键盘、筛选和取消行为。
4. 检查差异，获取远端状态，提交推送 main 并验证 GitHub Pages。

## 完成结果

- 规范升级 v0.4，增加筛选浮层与日期范围的统一组件规则、44px 紧凑操作和响应式验收要求；AGENTS.md 与 README 明确所有后续相关列表沿用。
- HTML 提供活动搜索和筛选演示：默认收起条件，桌面锚定弹层、手机底部浮层，长内容独立滚动；已选条件数量、搜索和清除同步更新结果。
- 日期入口并排显示起止值，复用中文滚轮的交互方式，先开始后结束，最终成对生效；支持上下限、单侧空值、返回修改、取消回退和清空范围。
- 同步应用仓库的同名规范与 HTML；两份规范同文，两份 HTML 仅字体引用路径不同。原表单、字体及图片保留。

## 验证情况

- 开始时 main 工作区干净，规范与应用文档一致。
- HTML 是静态本地示例，不连接真实学校系统；不引入依赖或构建框架。
- 脚本语法、内嵌 JSON、重复 ID、静态资源与锚点、两仓库差异检查通过；原图片与填写表单逐字一致。
- 390/768/1280px 浏览器视口下，浮层打开前后结果列表文档位置相同，普通筛选高度 44px，无横向溢出。320px 加放大文字时筛选内容 502px、可视区 408px，支持内部滚动且底部按钮保持可见。
- 搜索、条件计数、重置、日期开始后自动选结束、结束下限与成对确认正常；已有 9 月 14—30 日范围修改后取消，原值完整保留。关闭后焦点正确返回范围或筛选入口，原表单必填校验正常。
- 内置浏览器控制台无 error。浏览器模拟验证不代替真实设备验收；Pages 沿用 main 根目录自动发布，推送后核对正式网址。
