# 清北复交校园移动服务：配色与 UI 对标

研究日期：2026-09-09。对应 Metaversity v0.2 候选方案。

## 结论

建议以 **交我办蓝 #016AED + 白色内容表面 + 中性浅灰背景** 为主线。该蓝色有交大公开设计规范依据，适合作为校园办事类产品的操作主色。借鉴其他学校的信息分组和任务表达；不把四校色彩混在一套导航里。

本轮查看的是公开商店截图、校方功能介绍配图和官方手册中的界面，不代表已登录测试各校当前全部页面。商店宣传图及手册可能落后于实际版本；没有官方色号的学校只描述肉眼观察，不宣称提取到了官方设计变量。

## 对 Metaversity 的具体调整

1. 主色从墨绿改为 #016AED，按压态 #0058C7，浅底 #F2F7FF。背景改为 #F5F6F8，文字采用中性灰阶。这些配套值是本项目选择。
2. 课程和进度摘要使用白底、蓝色数字或细色条，减少整张深色填充。照片、轮播和内容区继续保留，让校园内容提供丰富度。
3. 常规卡片圆角 12、控件 8、小标签 6、大面板 20；统一同类样式和内边距。尺寸是本项目候选规则，不声称照搬某校标准。
4. 底部仍只有「首页」「个人」；白底、灰色未选中项、蓝色选中项，并配加粗图标及短标记。参考四校的样式，不复制其栏目数量。
5. 搜索、常用服务、分类服务、内容列表使用共同组件规则。借鉴分组逻辑，不在此确定首页固定布局，也不因此新增 AI 搜索或推荐业务。

## 取舍

- 采用：单一操作主色、中性背景、分组标题、稳定的图标体系、可读的状态和任务摘要。
- 按场景采用：品牌色头部、校园照片、轮播、彩色分类图标。不能每个区块都抢占视觉重点。
- 不直接照搬：学校标志、身份卡、专属插画、固定栏目数量、某张旧截图的字号；避免密集小入口挤压点击区域。
- 交大接入规范中「移动页面不提供退出登录」面向嵌入交我办的业务子页面，本项目独立 APP 不直接套用该业务约束。
